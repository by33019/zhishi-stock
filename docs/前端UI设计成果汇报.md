# AI 智能股票分析平台前端 UI 设计成果汇报

## 1. 成果概览

本次已在 `frontend/` 建立可独立运行的 Vue 3 高保真前端原型，产品名称采用“知势”。设计覆盖 PRD 中游客、登录用户和管理员的核心页面，并以 Mock API 还原行情、板块、资讯、自选、AI 研究和系统运营场景。

前端不是传统后台 CRUD 模板，而是采用“研究终端 + 财经编辑部”的组合视觉：深墨绿研究导航、暖纸色内容画布、中文衬线标题、紧凑数据排版和证据型 AI 报告共同建立产品识别度。

## 2. 设计原则

1. 证据优先：行情、事件、引用和风险说明在同一研究上下文中呈现。
2. 符合 A 股认知：上涨使用红色，下跌使用绿色，所有行情显示数据截止时间。
3. AI 有边界：AI 输出固定包含核心结论、量价依据、事件线索、风险和免责声明。
4. 信息分层：总览强调盘面结构，详情强调证据链，工作台强调问题到报告的过程。
5. 桌面优先、移动可用：MVP 以桌面工作台为主，同时提供无水平溢出的移动阅读布局。

## 4. 技术实现

- Vue 3 + TypeScript + Vite 构建 SPA。
- Vue Router 管理公开、用户和管理员页面元数据。
- Pinia 管理导航与 AI 侧栏状态。
- ECharts 按路由懒加载，绘制市场广度、成交趋势和 K 线。
- Mock API 统一使用 `success/code/message/data/traceId/timestamp` 返回外壳。
- Snowflake ID 在前端全程使用字符串，避免 JavaScript 数值精度问题。
- 视觉 Token 集中维护在 `src/styles/tokens.css`，业务页面按壳层、总览和业务样式分层。

## 7. 后端接入边界

当前 UI 使用 Mock 数据，不包含真实登录、行情 API、新闻 API、SSE 或 WebSocket 连接。后端接入时应优先替换服务层，不改动页面结构：

1. 将 `mockApi.ts` 替换为 Axios REST 客户端，并接入统一错误处理与 JWT 刷新。
2. 将 AI 报告定时模拟替换为 SSE 流式响应，保留取消、超时和证据状态。
3. 将行情新鲜度与 AI 任务状态接入 WebSocket，页面继续按当前状态标签展示。
4. 接入真实权限后，在路由守卫中落实游客、用户和管理员访问控制。
