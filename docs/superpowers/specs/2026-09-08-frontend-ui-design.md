# AI 智能股票分析平台前端 UI 设计

## 目标

在项目根目录新增可运行的 Vue3 高保真界面原型，覆盖 PRD 的核心前台流程和管理端基础视图。第一版使用 Mock API，但路由、类型、交互状态和模块边界需与 `Architecture.md`、`RESTful-API.md` 一致，以便后续替换为 Spring Boot API。

## 视觉方向

产品采用“研究终端 + 财经编辑部”语言，而不是常见蓝紫渐变后台模板：

- 暖纸色背景用于长时间阅读，深墨蓝侧栏形成稳定工作区边界。
- A 股语义使用朱红表示上涨、松绿色表示下跌，同时配合箭头、正负号和文字避免只依赖颜色。
- AI 使用琥珀金作为独立语义色，强调“研究辅助”而不是神秘霓虹效果。
- 标题使用偏编辑感的中文衬线字体，正文与数字使用 Manrope 和中文无衬线字体。
- 卡片使用细边框、克制阴影和不同尺度，避免所有信息都变成相同圆角白卡。
- 页面首屏使用有节奏的淡入与位移动画，尊重 `prefers-reduced-motion`。

## 信息架构

桌面端采用“深墨左侧导航 + 顶部全局搜索 + 中央研究画布 + 可收起 AI 侧栏”。核心路由包括：

- `/market`：市场总览、指数、市场广度、成交趋势、热点板块、行情榜单和资讯线索。
- `/rankings`：涨幅、跌幅、成交额和涨跌停榜。
- `/sectors`、`/sectors/:id`：板块排行、板块详情、走势和成分股。
- `/stocks/:id`：个股行情、分时/K 线、主营业务、关联资讯和场景化 AI 入口。
- `/news`：新闻与公告筛选、来源和数据状态。
- `/watchlist`：自选分组、行情、资讯数量和快捷分析。
- `/ai`：市场、板块、个股、风险和多标的比较工作台。
- `/history`：AI 会话、报告、引用和反馈历史。
- `/login`：登录与游客价值说明。
- `/admin`：用户权限、Provider、同步任务、数据质量和 AI 运营概览。

## 组件与状态边界

- `AppShell` 负责导航、搜索、交易状态、用户入口和 AI 侧栏容器。
- `MetricCard`、`StatusPill`、`QuoteTable`、`NewsList`、`SectionHeader` 为业务共享组件。
- `BaseChart` 封装 ECharts 生命周期，不将图表实例写入 Pinia。
- `AiResearchPanel` 展示任务状态、流式段落、证据与风险声明。
- `mockApi` 返回与 REST 文档字段一致的数据，页面不直接引用 Mock 常量。
- Pinia 只保存用户、市场快照和 UI 会话状态；大规模图表点和历史报告留在页面局部状态。

## 关键交互

- 顶部搜索支持代码、名称和拼音结果，300ms 防抖，键盘可访问。
- 实时状态始终显示数据时间；模拟行情更新时保持 REST 快照与 WebSocket 增量概念。
- 游客点击自选、AI、历史或导出时进入登录页并保留返回路由。
- 个股页点击“AI 解读”打开右侧研究栏，不跳离当前行情上下文。
- AI 面板区分准备、排队、生成、校验、完成、受限和失败状态，最终报告固定展示风险与免责声明。
- 榜单、资讯筛选和时间范围同步到 URL Query，为后续真实接口接入保留契约。

## 响应式与可访问性

- 核心验收宽度为 1440px 和 1280px；1024px 下压缩侧栏，768px 以下改为顶部导航和单列卡片。
- 键盘焦点清晰，按钮具备可读名称，图表同时提供数据摘要。
- 正文和背景对比度满足 WCAG AA；上涨/下跌同时使用符号和文本。
- 不使用无限动画；降低动态偏好下关闭加载位移与循环光效。

## 验证范围

- Vitest 覆盖路由元数据、行情格式化、Mock API、核心页面内容和 AI 状态转换。
- `vue-tsc` 和 Vite Build 验证类型与生产构建。
- Playwright 在 1440px 与 390px 视口检查首页、个股、AI 侧栏、导航和登录流程，并收集控制台错误。
- 核心页面通过 Figma Capture 写入新建设计文件，作为后续视觉评审基线。

## 明确边界

- 本轮不接真实后端，不实现真实 JWT、SSE、WebSocket 或第三方 API，只保留服务层和可视状态。
- 本轮不实现实盘交易、下单、组合收益、价格预测、社区或付费订阅。
- 不复制 Mobbin 或 One Page Love 的具体页面与素材，只参考信息层级、高对比操作和编辑式留白。
