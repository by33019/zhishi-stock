# 前端字体层级优化设计

## 1. 问题背景

当前 Web 端字体层级存在明显失衡。浏览器实测显示，页面一级标题约为 `46px` 至 `50px`，而模块说明、表单标签、表格内容、状态信息和辅助文字大量处于 `6px` 至 `10px`。标题与正文的倍率超过 5 倍，导致标题压迫感强、主体信息阅读困难，并且该问题同时存在于 AI 研究、市场总览、行情榜单、板块、个股、资讯、自选、历史、登录和系统管理页面。

本次优化采用全局语义化字体体系，不通过页面缩放、浏览器 `zoom` 或单页覆盖掩盖问题。

## 2. 优化目标

- 降低一级标题的视觉压迫感，使页面标题服务于信息定位而非占据主要阅读空间。
- 将正文、表格、表单和状态信息提升到桌面端舒适阅读区间。
- 保留“财经研究终端 + 编辑阅读”的品牌气质，以及衬线标题与无衬线正文的字体搭配。
- 所有业务页面使用同一套语义化字号 Token，避免继续增加零散硬编码值。
- 在字号增大后同步校正行高、控件高度、列宽和间距，防止换行、遮挡与水平溢出。
- 保持桌面端信息密度，并确保 390px 移动端仍可顺畅浏览。

## 3. 不在本次范围

- 不改变产品配色、品牌标识和整体视觉方向。
- 不调整业务流程、页面路由和 Mock 数据结构。
- 不新增用户自定义字号或紧凑、舒适模式切换。
- 不重构与字体可读性无关的组件和业务逻辑。

## 4. 字体体系

在 `tokens.css` 中新增以下语义化 Token：

| Token | 桌面端字号 | 用途 |
|---|---:|---|
| `--text-caption` | `12px` | 时间、代码、来源、状态补充说明 |
| `--text-label` | `13px` | 表单标签、表头、标签、次要操作 |
| `--text-body` | `14px` | 正文、表格单元格、表单控件、按钮 |
| `--text-body-lg` | `15px` | 页面描述、重点说明、空状态说明 |
| `--text-card-title` | `18px` | 卡片标题、列表内容标题 |
| `--text-section-title` | `20px` | 模块标题、研究报告章节标题 |
| `--text-page-title` | `clamp(36px, 2.6vw, 42px)` | 常规页面一级标题 |
| `--text-display-title` | `clamp(40px, 3vw, 48px)` | 仅登录品牌叙事等展示场景 |

Web 端可见业务文字原则上不得低于 `12px`。装饰性图形不受该限制，但不得承载业务信息。

## 5. 字体与行高规则

- 页面标题使用 `var(--font-serif)`，行高为 `1.18`，字重控制在 `600` 至 `650`。
- 模块标题使用 `var(--font-serif)`，行高为 `1.35`。
- 正文和表单使用 `var(--font-sans)`，行高为 `1.6` 至 `1.75`。
- 标签、表头和状态文字行高不低于 `1.4`。
- 行情数字继续使用等宽数字特性，不因字号调整改变涨跌颜色语义。
- `eyebrow` 提升到 `12px`，通过字距和字重维持辅助标题属性。

## 6. 页面映射

### 6.1 AI 研究

- 一级标题由约 `46px` 调整到最高 `42px`。
- 页面描述提升到 `15px`。
- “研究设置”“来源引用”提升到 `14px` 并加强层级。
- 分析场景、目标标的、时间范围和问题模板标签提升到 `13px`。
- 选择器、问题模板、输入框和按钮文字统一到 `14px`。
- 空状态标题为 `20px`，说明为 `14px`。
- AI 报告章节标题为 `20px`，报告正文为 `14px`，引用卡正文不低于 `13px`。

### 6.2 市场、榜单、板块与个股

- 市场主标题和通用页面标题最高不超过 `42px`。
- 页面描述统一到 `15px`。
- 卡片模块标题统一到 `20px`，模块说明不低于 `12px`。
- 表格正文统一到 `14px`，表头与代码信息统一到 `12px` 至 `13px`。
- 行情核心数字保留更大的数据字号，但标签和涨跌说明不低于 `12px`。

### 6.3 资讯、自选、历史、登录与管理端

- 资讯正文、来源、时间和标的标签分别映射到正文、标签和辅助文字 Token。
- 自选卡片的公司名称、价格、字段标签和操作按钮提高可读性。
- 历史报告摘要和筛选项不低于 `13px`。
- 登录表单标签、输入内容、辅助操作和协议说明不低于 `12px`。
- 管理端指标、服务状态和任务状态使用与业务端一致的文字基线。

## 7. 响应式规则

- `700px` 以下页面标题使用 `32px` 至 `36px`，避免中文长标题挤压。
- 移动端正文仍保持 `14px`，辅助文字不低于 `12px`。
- 字号提升后允许卡片内容自然增高，不通过缩小文字维持固定高度。
- 表格在窄屏下优先横向滚动或转换为卡片，不压缩到不可读字号。

## 8. 技术实施

- 在 `tokens.css` 建立唯一字体尺度来源。
- 将 `base.css`、`shell.css`、`pages.css` 和 `business.css` 中承载业务信息的硬编码字号替换为语义 Token。
- 对少量特殊展示数字保留独立字号，但其说明文字必须遵循最小字号规则。
- 不使用 `!important` 作为批量修复手段，避免继续增加样式优先级债务。
- Playwright 视觉检查增加字体下限和一级标题上限断言。

## 9. 验收标准

- 桌面端常规页面一级标题计算字号不超过 `42px`。
- 桌面端页面描述计算字号不低于 `15px`。
- 表单标签、模块辅助信息和状态信息不低于 `12px`。
- 正文、表格内容、输入框和主要按钮不低于 `14px`。
- AI 研究页的研究设置、时间范围、问题模板和来源引用在 1440px 下无需缩放即可清晰阅读。
- 市场总览、AI 研究、行情榜单、个股详情、登录页和 390px 移动端无水平溢出。
- 浏览器控制台无错误、警告和 ECharts 诊断信息。
- 全量单元测试、类型检查和生产构建通过。
